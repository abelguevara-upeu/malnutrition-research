# Manuscrito

Todo lo del artículo, separado del código del proyecto.

| Carpeta | Contenido |
| --- | --- |
| `articulo/` | Manuscrito LaTeX (`art-prisma.tex`), figuras para Prism y documentos de apoyo |
| `referencias/` | Bibliografía (`referencias.bib`) y PDFs de artículos |
| `leapspace/` | Búsquedas de literatura en LeapSpace |
| `validacion/` | Instrumento TAM2, formulario y documentos del panel de especialistas (`entrevista/` no se versiona) |
| `presentaciones/` | Presentaciones e informes de avance por semestre |
| `assets/` | Scripts y estilos para generar PDF y diapositivas |
| `pendientes.mmd` | Tablero de pendientes |
